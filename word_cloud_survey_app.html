連線至 API 失敗 (Failed to fetch) 診斷對策：
  1. 權限未開放：在 Google Apps Script 右上角點選「部署」➔「管理部署」➔「誰有權限存取」必須設定為 「所有人 (Anyone)」。
  2. 使用了測試網址：請確認網址結尾為 /exec，而非 /dev。
  3. 重新發布部署：修改 Apps Script 程式碼後，必須點選「部署」➔「新增部署」並更換新網址。
